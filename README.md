## About

BrightPath Tutorial Services is a mobile application that makes it easy for students and parents to find the right tutor. Students can search by subject and availability, book sessions, and keep track of their learning goals. Tutors get simple dashboard to manage their schedule and bookings.

## Features

• 🔍 Tutor Search and Filtering - Find tutors by subject, levels, and availability.
• 📅 Session booking - schedule one-on-one sessions
• 👤 User accounts - separate views for students and tutors

## Tech Stack

• **Framework** - React Native
• **Development** - Expo (Expo Go)
• **Languages** - JavaScript
• **IDE** - Visual  Studio Code

## Getting Started

Follow these steps to run the BrightPath app locally on your device or emulator.

## Prerequisites

Before you begin, make sure you have the following installed on your computer:
• Node.js (LTS version recommended)
• Git
• Expo Go app (Download this on your iOS or Android physical device from the App Store or Google Store)

## Installation

1. Clone the repository -
2. Navigate into the project folder
3. Install the dependencies using npm install

## Running the App

1. Start the Expo server:
    npx expo start
2. A QR code will appear in your terminal
3. To run the app:
   • On a physical phone: Open the Expo GO app on your phone and scan the QR code.
   • On an Android Emulator: Press 'a' in the terminal.
   • On an iOS Simulator(Mac only): Press 'i' in the terminal.
